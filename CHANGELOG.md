All notable user-facing changes to this project will be documented here.

## [0.8.1] - 2026-08-28

### Fixed

- Fixed printer, drawer, and room closeup staging and alignment.
- Improved scene test resilience when 3D layouts change.
- Refined return controls and corrected related project copy and labels.
- Updated the release workflow runtime.

## [0.8.0] - 2026-08-27

> First public prerelease. This version is available for external testing and is not the stable `1.0.0` release.

### Added

- Introduced the Lab 17 portfolio experience at `https://alinawu.com`.
- Added interactive room exploration with progressive content reveal.
- Added System Bulletin, Version History, and feedback entry points.

### Changed

- Established `https://alinawu.com` as the canonical public address.
- `www.alinawu.com` now redirects to the canonical root domain.
