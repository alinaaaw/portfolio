# Changelog

All notable user-facing changes to this project will be documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.9.0] - 2026-09-04

**Mobile Exploration Update**

> A substantial prerelease update that gives Lab 17 a purpose-built mobile experience while preserving the desktop laboratory.

### Added

- Added a dedicated portrait layout with mobile-first navigation, framing, and interaction guidance.
- Added a phone-style computer interface, a mobile Lab Log timeline, and an explorer sheet for moving between room areas.
- Added an interactive System Version History generated from the public changelog.

### Changed

- Reframed the room, computer, bookshelf, drawer, notebook, field case, contact card, and fax views for phones and tablets.
- Improved touch discovery with persistent scene markers, swipe guidance, and touch-friendly closeup hints.
- Centralized the displayed portfolio version around the package version and changelog release data.

### Fixed

- Fixed portrait clipping, overflow, scrolling, typography, and paper proportions across the main exploration flow.
- Fixed landscape-touch camera fitting, closeup guidance, and bookshelf marker visibility.
- Expanded automated checks for portrait isolation, release history, visitor links, assets, and 3D scene connectivity.

## [0.8.1] - 2026-08-28

**Interaction Alignment**

### Fixed

- Fixed printer, drawer, and room closeup staging and alignment.
- Improved scene test resilience when 3D layouts change.
- Refined return controls and corrected related project copy and labels.
- Updated the release workflow runtime.

## [0.8.0] - 2026-08-27

**Initial Public Preview**

> First public prerelease. This version is available for external testing and is not the stable `1.0.0` release.

### Added

- Introduced the Lab 17 portfolio experience at `https://alinawu.com`.
- Added interactive room exploration with progressive content reveal.
- Added System Bulletin, Version History, and feedback entry points.

### Changed

- Established `https://alinawu.com` as the canonical public address.
- `www.alinawu.com` now redirects to the canonical root domain.
