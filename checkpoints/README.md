# Checkpoints

This folder stores portable, read-only snapshots of completed portfolio
versions.

## Version 1

`alina-portfolio-version1.zip` contains the Version 1 source without generated
dependencies, caches, or local build output. Unzip it into a new folder if the
main project ever needs to be restored.

The same source is also preserved in the repository tag `version1`.

## Version 2

`alina-portfolio-version2.zip` contains the Version 2 source, including the
preserved Version 1 route, without generated dependencies, caches, or local
build output.

The same source is also preserved in the repository tag `version2`.
