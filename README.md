# Alina Wu Portfolio — Version 4

Version 4 is a warm, editorial personal portfolio. It introduces Alina first,
shows her work and interests clearly, and includes a small optional interaction
about how visitors explore.

The psychological-experiment idea is intentionally a supporting module rather
than the identity of the whole website. Its small amount of interaction state
exists only in browser memory and is never transmitted.
