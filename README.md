# Alina Portfolio — Version 2 Design

This branch contains only the **Focus Field** portfolio direction.

## Open locally

Double-click `START-WEBSITE.cmd`. Keep the command window open while viewing
the site, and press `Ctrl + C` when finished.

Local address: <http://127.0.0.1:3000/>

## Branch purpose

- Branch: `version2-design`
- Design: animated spatial Focus Field
- Status: active and independently editable
- Shared framework files stay at the repository root.
- Version 1 does not live in this branch; it is maintained separately in
  `version1-design`.

## Main files

```text
app/page.tsx              Version 2 content and interactions
app/layout.tsx            Version 2 metadata and page shell
public/site.css           Version 2 visual design
public/og.png             Version 2 social preview
VERSION-2.md              Design notes
START-WEBSITE.cmd         Local launcher
```

Commit each meaningful change to this branch so earlier states remain
available in Git history.
