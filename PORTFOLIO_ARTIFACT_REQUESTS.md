# Portfolio Artifact Requests

This file tracks the materials that would strengthen the portfolio from a clear written account into a visual, evidence-backed case-study collection. None of these materials is required for the current site to function.

## Priority 1 — Thermo Fisher: Robot-Assisted Tube Handling

The current drawer packet deliberately uses clearly marked placeholder metrics. Replace them with public-safe evidence before treating the project as a visual case study.

- Two or three YOLO detection images with bounding boxes.
- A Roboflow project screenshot, or a short dataset summary: classes, image count, and train/validation/test split.
- Training curves, final mAP / precision / recall, or a training-log screenshot.
- A photo or video frame showing the robot arm grasping, moving, or placing a tube.
- A simple public-safe system diagram: camera → YOLO26 → ROS2 → robot arm.
- If available, a confusion matrix or a few detection results from different operating conditions.

Do not include proprietary software screens, internal URLs, credentials, unreleased interfaces, customer information, defect identifiers, or confidential workflow details. One public-safe detection screenshot plus a small data summary is enough to begin.
